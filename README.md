# ⚽ Sports Website – HTML, CSS 

Sports Website is a **modern, responsive, and interactive web application** built using **HTML, CSS, and JavaScript**. The platform provides users with the latest sports news, event details, membership options, feedback forms, and contact information in a clean and engaging interface.  

The website is fully responsive and designed to deliver a smooth user experience across desktop, tablet, and mobile devices.

---

## 🚀 Features

• **Home Page** – Overview of latest sports events, news, and featured content  
• **Events Page** – Detailed listing of upcoming matches, tournaments, and sports events  
• **Membership Page** – Sign-up for memberships, subscription plans, and benefits  
• **Feedback Page** – Collect user feedback through a form  
• **Contact Us Page** – Contact form and details for inquiries  
• Responsive design for all devices  
• Interactive UI with hover effects and animations  

---

## 🛠 Technologies Used

• HTML5 – Page structure and content  
• CSS3 – Styling, animations, and responsive design
